Configuración inicial

Esta base de datos todavía no existe en este celular. Cargue el maestro, elija su usuario y defina su clave. Si se pierde la clave y no se exportó, los datos no se pueden recuperar.

1. Maestro de bienes

Archivo Excel (.xlsx, .xls) o .csv con las columnas IDCodigoAntiguo, Descripcion, Nombre, Ubicacion, Ambiente y Baja. Opcional: una hoja «Catalogo» con columnas Nombre, Ubicacion y Ambiente para ampliar las listas.

2. Usuario y clave

Elija un usuario y defina su clave: mínimo 10 caracteres y no solo números. Mejor una frase fácil de recordar.
